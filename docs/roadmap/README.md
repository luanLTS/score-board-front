# Roadmap Detalhado

Este diretório detalha as fases definidas em [PROJECT.md](../../PROJECT.md), com uma página por etapa do roadmap.

Use estes documentos para quebrar cada fase em tarefas menores, identificar dependências e decidir quais frentes podem ser executadas em paralelo.

1. [Fase 1: Placar Simples](./fase-01-placar-simples.md)
2. [Fase 2: Regras Configuráveis](./fase-02-regras-configuraveis.md)
3. [Fase 3: Persistência E Histórico](./fase-03-persistencia-e-historico.md)
4. [Fase 4: Gerenciamento De Partidas](./fase-04-gerenciamento-de-partidas.md)
5. [Fase 5: Torneios](./fase-05-torneios.md)
6. [Fase 6: Experiência Avançada](./fase-06-experiencia-avancada.md)

## Estrutura De Cada Fase

Cada arquivo segue a mesma estrutura:

- Objetivo da fase.
- Escopo incluído e fora de escopo.
- Dependências de fases anteriores.
- Entregáveis esperados.
- Tarefas pequenas.
- Tarefas que podem ser executadas em paralelo.
- Critérios de aceite.
- Riscos e decisões pendentes.

## Como Usar

Antes de iniciar uma fase, revise os critérios de aceite da fase anterior. Ao planejar a execução, prefira separar tarefas por domínio, UI, testes e documentação quando essas frentes não dependerem diretamente uma da outra.
